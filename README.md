# NexForma.3D

> **Dando forma às suas ideias, camada por camada.**  
> Fabricação digital aditiva & Impressão 3D sob medida.  
> Instagram: [@nexforma.3d](https://instagram.com/nexforma.3d)

## 🚀 Tecnologias

- **Vue 3** (Composition API, `<script setup>`)
- **Vite**
- **Tailwind CSS v4** (Dark-Mode Industrial com Obsidian `#0B0D10`, Carbon `#151921` e Ciano Neon `#00E5FF`)
- **Lucide Icons** (`lucide-vue-next`)

## 🛠️ Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
